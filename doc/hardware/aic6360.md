# Adaptec AIC-6360 SCSI

Two ISA16 controllers are available in **Storage controllers → SCSI**:

- **Sound Blaster 16 SCSI-2 (AIC-6360)** (`sb16_scsi`): the SCSI interface
  of the Creative CT1770/CT1779. Select the existing Sound Blaster 16 separately
  in Sound settings for audio. The SCSI interface has its own address and IRQ;
  it does not use the sound card's IRQ or DMA channels and has no boot BIOS.
- **Adaptec AHA-1520A** (`aha1520a`): the standalone adapter, with a 16 KB
  option ROM and a configurable BIOS address. No floppy controller is included.

Both default to I/O **340h**, IRQ **11**, and host SCSI ID **7**. The alternate
I/O address is **140h**; IRQs **9, 10, 11, and 12** are supported. Attach SCSI
hard disks, CD-ROMs, or other SCSI targets to IDs 0–6 on the adapter's bus.
For the SB16 interface, use a guest AIC-6260/6360 driver such as ASPI2DOS;
DOS CD-ROM access also needs ASPICD and MSCDEX. BIOS-less controllers cannot
boot a disk without another boot device and a guest driver.

The AHA-1520A uses `roms/scsi/adaptec/aic6360-v1-20l.bin` in the ROM search
path (Adaptec AIC-6360 BIOS 1.20L, 16384 bytes). The ROM is supplied separately,
as with other 86Box firmware. Its default mapping is DC000h; BIOS mapping can
be disabled in the adapter's configuration.

The implementation supports initiator operation, automatic selection and
selection timeouts, SCSI PIO, the 128-byte host FIFO, 8/16/32-bit host PIO,
24-bit transfer counting, interrupt masks, software interrupts, reset, and
16/32-byte stack RAM. Targets remain connected for the duration of a command;
SDTR and WDTR negotiate asynchronous, eight-bit transfers. ISA DMA, target
mode, and disconnect/reselection are not implemented; use programmed I/O.

## Validation

`aic6360_tests` exercises the registered I/O handlers with simulated SCSI
targets. It covers detection, stack wrap, interrupt acknowledgement, phase
mismatch, timeout/cancellation, IDENTIFY and negotiation, long-message
rejection, BIOS-style preloaded PIO, command/status/message completion,
FIFO transfers with odd residuals, counter wrap, 32-bit aliases, reset, ROM
mapping, and bus exhaustion.

Configure with `-DBUILD_TESTING=ON`, build `aic6360_tests`, then run:

```sh
ctest --test-dir <build-directory> -R '^Aic6360\.' --output-on-failure
```

During development, the separately supplied 1.20L BIOS was also executed in a
16-bit CPU harness against the controller's actual I/O handlers: empty-bus
initialization, disk detection/INT 13h installation, and a 512-byte INT 13h
sector read completed successfully. This uses a simulated disk and BIOS
services; it is not an end-to-end DOS or Windows guest compatibility test.
